GGJ 2016 心得

由於這次是第一次參加 Game Jam

很多東西在一開始都還沒有掌握

但是很高興的第一次參加 Game Jam 就能跟這麼給力的隊友組隊

讓遊戲可以順利完成

我們在第一天的晚上花費了多時間在討論遊戲主題 Ritual

這邊算是最容易鬼打牆的階段

經過漫長的討論

最後總算是歸納出了一個遊戲方向

並且在隔天的凌晨2點左右完成了遊戲企劃

接著開始進行工作分配

由於這次我們很幸運的團隊能力分配的很平均

3程式、1美術、1音樂、音效

所以在工作分配上還算順利

不過因為沒有企劃及PM角色

所以最後是由我來擔任PM來輔助其他成員製作

參加 Game Jam 最大的收穫就是

會知道原來台灣從來不缺少熱血的開發者

大家幾乎都是徹夜開發遊戲

而且都討論的相當熱烈

在48小時內開發一款遊戲

不但享受開發遊戲的樂趣

還把原本短則三個月，長達一年以上的開發時程

濃縮到短短48小時中

對於沒有實際參與過整個遊戲開發的開發者們

是一個相當難得的機會
